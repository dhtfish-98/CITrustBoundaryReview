CITrustBoundaryReview replaces the selected defensive mechanism with eight new Python runtime modules. Its lexer/AST, flow lattice, ordered output/environment propagation, per-event job analysis, artifact models, CLI and tests were written for this finite contract. It does not shell out to zizmor, call its Rust libraries, reproduce its full source-capability CSV, or claim all of its script-action sinks. It extends the chosen local trust-boundary theme with explicit modeled output/env/job/artifact propagation. It excludes permission-policy, pin-policy and secret-content checking so that its main mechanism is distinct from WorkflowPermissionReview.

The only runtime dependency is the trusted parser `PyYAML==6.0.3`, downloaded from official PyPI and verified against the release artifact hash. Its original MIT notices remain in its separately installed distribution; this project does not redistribute PyYAML source or its wheel. The runtime uses BaseLoader's parser events with no object construction. The hash lock enumerates that release's binary wheel hashes; it does not accept an unverified source build as the installed runtime dependency. The dependency is not vendored as copied executable source.
